# פנינים ישראליות

מקומות קטנים ומיוחדים מהמלצות של חברים.

הקוד של האתר. ההוראות המלאות לעבודה על הפרויקט נמצאות ב-`CLAUDE.md`.

## הרצה מקומית

```
npm install
npm run dev        # http://localhost:3000
npm run build      # בודק את הנתונים ובונה
```

- הנתונים: `data/places.json` (איך מעדכנים: `scripts/README.md`).
- כל PR מקבל קישור Preview מ-Vercel; מיזוג ל-`main` מעלה לאתר החי.
